# Project References

The following genuine, accessible references and official documentation were used in designing and developing this Library Book Lending Management System:

1. **Node.js HTTP Standard Module Documentation**  
   https://nodejs.org/docs/latest/api/http.html  
   *Reference for creating the lightweight native HTTP web server, managing request lifecycle streams, and routing without external web frameworks.*

2. **MySQL2 Official Repository & Documentation**  
   https://github.com/sidorares/node-mysql2  
   *Reference for creating a high-performance MySQL connection pool, executing prepared statements with parameterized queries, and handling SQL errors like duplicate entries.*

3. **Bootstrap 5.3 Official Documentation**  
   https://getbootstrap.com/docs/5.3/getting-started/introduction/  
   *Reference for building a responsive grid system, KPI stat cards, interactive modal dialogs, form validation indicators, and accessible toast notifications.*

4. **MDN Web Docs: HTML Drag and Drop API**  
   https://developer.mozilla.org/en-US/docs/Web/API/HTML_Drag_and_Drop_API  
   *Reference for implementing native browser drag events (`dragstart`, `dragend`, `dragover`, `dragleave`, `drop`) and transferring book identifiers across lending drop zones.*

5. **MDN Web Docs: Using the Fetch API**  
   https://developer.mozilla.org/en-US/docs/Web/API/Fetch_API/Using_Fetch  
   *Reference for executing asynchronous HTTP requests (`GET`, `POST`, `PUT`, `PATCH`, `DELETE`) with `async`/`await` and parsing JSON payloads in vanilla JavaScript.*
